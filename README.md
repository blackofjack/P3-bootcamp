How to Use
1. Open the AI Emotion Detector in your browser.
2. Type your message, thoughts, or feelings into the input field.
3. Click the Send/Analyze button.
4. The AI will process your text and detect the possible emotion.
5. View the generated emotional response displayed on the screen.
6. Continue sending messages to interact with the AI in real time.
Tips
• Try different emotions or sentence styles for varied results.
• Use clear and complete sentences for better emotion detection.
• Works best with internet connection enabled for API requests.
